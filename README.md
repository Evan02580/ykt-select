# 雨课堂答题辅助

本地题库检索与答题辅助。

**！！！本项目不提供题库**

1. 自行找好包含题目、选项和答案的 TXT 题库。
2. 使用 Python 3.10+ 转成 JSON，无需安装额外依赖：

   ```bash
   python txt_to_question_bank.py "题库.txt" -o question_bank.json
   ```

3. 在 Chrome 浏览器安装篡改猴（Tampermonkey）扩展。
4. 在网页中点击篡改猴扩展，添加新脚本，将 `答题辅助.js` 的全部内容粘贴进去，保存并启用。
5. 打开习题页面，点击助手中的「导入 JSON」，选择生成的 `question_bank.json`。点击「识别当前题目」或输入关键词检索，也可开启「自动选择选项」。

遇到防复制文字，点击「开启真实画面识别」并共享当前标签页，或导入题目截图。答案请核对，提交需手动操作。
